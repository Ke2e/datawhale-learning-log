## 已确认的方案（Solution）

### 1. 资料与课程隔离

- 官方仓库独立克隆，本地可读取和运行；主库保存个人笔记、实验、验收记录及来源版本。克隆主库的人需要另外获取上游材料，这是已接受的取舍。
- 加入课程时记录上游版本。更新先说明与当前学习相关的差异，经 Asize 确认后进行；旧 Task 的验收依据及证据保留，不自动重判。
- 首门课程直接放在工作区根目录的 `easy-data-x-ai/`，其内聚合个人学习笔记和原课程仓库；原课程仓库保持独立 Git 仓库，仅该子目录排除出学习主库。课程目录及个人笔记仍由主库跟踪，实验按需创建。
- 子目录名称已确认：`note/`（个人笔记）和 `upstream/`（官方材料）。课程入口记录学习目标、上游位置/版本及 Task 索引；忽略规则仅覆盖 `easy-data-x-ai/upstream/`，不覆盖课程入口或笔记。
- 父目录也有 Git 仓库，接入时单独核对其边界；如确需修改父仓库忽略规则，另行取得 Asize 授权。
- Task 笔记保留原始内容，追加经确认的验收证据与薄弱点。暂不另建验收目录或重复进度表。

### 2. 自学、教学与独立验收

- 本课程目标是产品判断与工程实现并重：能解释方案取舍，也能动手验证关键机制；不默认要求完整产品。
- 默认先由 Asize 阅读材料、记录笔记并尝试作业，再由助手诊断。卡点按需教学，不提前输出完整讲解或答案。
- 追问沿用“事实 → 决策 → 反事实”，逐题等待作答和反馈，而不是一次发出整套题与标准答案。
- 两个结果分别记录：课程要求是否满足；是否已有独立掌握证据。允许“课程作业完成，但理解仍需补强”，不混为一个通过状态。
- 概念类使用新场景验证解释与判断；工程类优先复用课程作业，必要时补关键变更、对比或故障分析。口头解释不能替代动手结果。
- 验收中需要提示时转入补强教学；补强后换场景或关键变更复验，同题纠正后的答对不直接算独立掌握。工程操作允许查官方文档，但助手提供的关键解法需标明为受助。

### 3. 记录、扩展与技能试行

- 助手整理问题、Asize 的作答或经确认摘要、提示情况、实践结果、薄弱点和结论；经 Asize 确认后回写，不改写其原始笔记来制造掌握印象。
- GitHub Issues 管理正式 Task 要求与进度，笔记提供证据链接。本文件记录需求与取舍；正式任务发布遵循 Issue 约定，避免出现两个互相冲突的状态来源。
- 主线达标后，每次推荐一个相关 X 章节或小实验，说明要验证什么，由 Asize 选择探索或继续主线。必要补强属于主线，不包装成可选扩展。
- 先用项目内陪练约定跑通一个 Task，再决定是否封装专用 skill；保留原版 teach/grill，不直接串联其默认“先讲后练”和“给推荐答案”行为用于验收。
- 对话中的分项选择即时沉淀到对应章节；新建议留在未决事项，只有明确确认后才升为决定。用户修订时更新现行决定，并留下简短的修订依据，不保存整段聊天。

## 边界与风险

| 情况 | 处理 |
|---|---|
| 官方作业或打卡规则不明 | 保留“未核实”；可以报告已查看的材料与个人掌握证据，不能宣称官方通过。 |
| 已运行课程示例但无法解释或迁移 | 运行结果保留；独立掌握继续补强，不因“能跑”直接通过。 |
| 缺少模型 Key、数据库或无法运行 | 明确受阻项；可选离线验证仅证明其覆盖的能力，不伪造真实服务结果。 |
| 提示后答对 | 保留受助事实，并用新场景复验。 |
| 上游更新或图文冲突 | 记录对应版本/来源，按已确认优先级处理；涉及学习基准更新时再获确认。 |
| 多课程切换 | 使用各自课程入口、版本、Task 与笔记；不把另一门课的状态或证据套入当前 Task。 |

## 可验证的验收条件（Acceptance criteria）

以下是未来落地本方案的条件，不表示现在已经通过课程验收。

- AC-1 接入任一课程后，可以从课程入口定位上游仓库、材料版本及本地位置；上游原文不进入主库跟踪内容。
- AC-2 映射本期任务时，Task02 保持 P1/D1/I1，D1 为 API 基础；Task09 保持 P5/D5/I8，P5 为综合案例与度量；Task08 包含跨页的 I7。
- AC-3 缺少官方明确要求或提交信息时，课程要求核对保留未核实项，不把个人验收结论标成官方通过。
- AC-4 同一 Task 的课程要求核对和独立掌握结论能分别查阅，每个结论都有对应要求或作答/实践证据。
- AC-5 需要提示的验收进入补强，只有不同场景或关键变更的复验结果可成为新的独立掌握证据。
- AC-6 工程能力的通过结论含实际操作、关键变更及观察结果；只有口头解释或助手生成代码时不满足该条件。
- AC-7 未获得 Asize 确认时，不改写原始笔记、不回写学习验收结论、不变更对应 Issue 状态。
- AC-8 未确认扩展选择时，不自动开始 X 章节或实验；未验证首个试行 Task 前，不改原版 skill 或创建专用 skill。
- AC-9 新会话可从文档读出当前决定、资料来源和未决事项；源文件仅保留必要修订依据，而非逐字聊天记录。
