## 资料与版本

- 官方课程：[datawhalechina/easy-data-x-ai](https://github.com/datawhalechina/easy-data-x-ai)。
- 已检出的学习基准：[`3ba4823ed014ad9057e1c94e333222113556d4ab`](https://github.com/datawhalechina/easy-data-x-ai/commit/3ba4823ed014ad9057e1c94e333222113556d4ab)。接入日期：2026-11-16。已核对 HEAD、官方来源及干净工作区。

- 个人笔记位置：`note/`，与本课程入口一起由学习主库管理；实验有明确需求时再创建。

## 陪练与记录边界

- 默认自学、记笔记和尝试在先，再通过“事实 → 决策 → 反事实”逐题诊断；卡点按需教学。
- 课程要求核对与独立掌握分别记录。提示后转入补强，换场景或关键变更复验；工程能力需要真实操作及观察证据。
- 原始笔记由 Asize 保留；助手整理的验收记录经确认后追加。扩展章节与实验逐项确认，不自动展开。
- Task01 当前只有模板，尚未确定个人验收范围；不将 F1/F2、OpenClaw 安装、模型 Key 或数据库配置自动列为必做。
